# Translation policy

Jelyvo ships English and French. The other inherited translations are archived under
`app/translations-legacy`; this fork no longer synchronizes with upstream Crowdin.

## Support levels

- `values/strings.xml` (English) is the source of truth and is required for every user-facing key.
- `values-fr/strings.xml` (French) is maintained with the fork and is required for every new
  Jelyvo feature before release.
- The other inherited translations are excluded from the APK. Restore a locale to `app/src/main/res`
  and add it to `localeFilters` only after its translation has been completed and reviewed.

The supported locale list must match the resources actually packaged. Do not copy English text into locale-specific files merely to make key counts match;
that would hide the untranslated state and prevent Android's normal fallback.

## Adding or changing text

1. Add or update the English resource.
2. Add or update its French equivalent, including matching format arguments and plural quantities.
3. Reuse an existing key when the product meaning is identical; do not reuse a close translation
   for a different concept.
4. Build the app so Android resource validation catches malformed XML and incompatible format
   arguments.
5. Additional translations are welcome when reviewed by a speaker of that language.

The same policy applies to `plurals`, string arrays, accessibility descriptions and notification
channels.
