# Translation policy

Jelyvo speaks French only, whatever language the phone or watch is set to. `AppLocale` on the phone
and `WatchLocale` on the watch set it at startup. It also makes French the default locale, so YouTube
answers in French too. The Mac client is written in French directly.

`values/strings.xml` stays the source of each key and the fallback Android requires, but it should
never reach the screen: `FrenchTextTest` fails if a key has no French version, if the French text is
garbled, or if it uses an English word. Brands and technical names stay as they are (YouTube, Chromecast,
Wi-Fi, USB, OLED), and so do words French has made its own (album, radio, podcast, karaoké, cache).

Text that comes from elsewhere is out of the app's hands: track names, some YouTube categories such as
"Singles et EP", and the system's own sheets, which follow the phone's language.

The other inherited translations stay archived under `app/translations-legacy`, excluded from the APK.

## Adding or changing text

1. Add or update the English resource.
2. Add or update its French equivalent, including matching format arguments and plural quantities.
   Use French words: `FrenchTextTest` holds the file to this.
3. Reuse an existing key when the product meaning is identical; do not reuse a close translation
   for a different concept.
4. Build the app so Android resource validation catches malformed XML and incompatible format
   arguments.
5. Additional translations are welcome when reviewed by a speaker of that language.

The same policy applies to `plurals`, string arrays, accessibility descriptions and notification
channels.
